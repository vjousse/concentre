Starting with version 0.10, Pomodorolm is called **Concentré**.

# Why a new name

The old name was built on “Pomodoro”, which is a registered trademark. Concentré is a name of its own: it’s French for “focused”, which is what the app is for.

# What changes for you

Nothing. Your settings are kept, and updates keep coming through the channel you installed the app from.

Package names and identifiers (Flathub, Snap, winget) still use `pomodorolm` for now, so that existing installs keep updating normally. The [installation page](@/installation.md) lists them all.

# A home for the project

Concentré now has its own website, [concentre.org](https://concentre.org), and this news page. Each notable release gets a short post here, and you can follow them with the [Atom feed](/news/atom.xml).
